## 🌟 Overview & Key Architecture

**SparkX 3.0** is an innovation platform structured around a single-codebase, dual-audience experience that seamlessly caters to:
- 🇮🇳 **Indian Students:** Semester-specific tracks (**SparkX Pro** for 7th Sem, **SparkX Novel** for 3rd & 5th Sem, and **30-Day AI Challenge**), with an on-campus physical showcase and prizes in INR (₹10,000 / ₹8,000 / ₹5,000).
- 🌍 **International Students:** The global **30-Day Innovation Challenge** with 100% online virtual participation, 4 specialized enterprise AI problem statements, global jury evaluation, and cash prizes in USD (USD 150 / USD 100 / USD 80).

### Key Features
1. **Interactive Audience Selector:** Switch between `🇮🇳 India` and `🌍 International` via the hero banner, navbar toggle, or URL query (`/?audience=india` or `/?audience=international`).
2. **Live Countdown:** Real-time synchronized countdown ticking down to the Grand Exhibition on 25 November 2026.
3. **4 Deep AI Challenge Tracks:**
   - **Challenge 01:** AI-Powered Intelligent Event Planning & Management Platform
   - **Challenge 02:** AI-Powered Interview Preparation & Career Readiness Assistant
   - **Challenge 03:** AI-Powered Intelligent Lab SPOC (Virtual Lab Ambassador)
   - **Challenge 04:** AI University Copilot & Intelligent Campus Platform
4. **Interactive Modals:** Detailed architecture blueprints, modules, deliverables, and tech stacks for every challenge.
5. **Interactive FAQ:** Real-time search filter and categorized accordion (General, Indian, International, Deliverables).
6. **Academic Leadership & Global Advisory:** Showcases University Patrons, Silicon Valley industry executives, and faculty coordinators.

## 🛠️ Technology Stack

- **Language:** TypeScript
- **Bundler / Dev Server:** Vite
- **Styling:** Custom CSS Design System (Deep Navy Academic Theme, Gold & Electric Blue Accents, Glassmorphism, Micro-animations)
- **State Management:** Reactive Custom Event & LocalStorage State Machine with URL sync
- **Effects:** Canvas Confetti

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/ParthK0/Sparkx-3.0.git

# Navigate to project directory
cd Sparkx-3.0

# Install dependencies
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### Production Build
```bash
npm run build
npm run preview
```
